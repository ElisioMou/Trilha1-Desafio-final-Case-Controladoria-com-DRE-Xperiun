# Trilha1-Desafio-final-Case-Controladoria-com-DRE-Xperiun
## Desafio: Dashboard de Controladoria DRE para a empresa XP-Bucks

## Objetivo
O objetivo deste desafio é criar um **dashboard interativo** que permita monitorar de maneira eficaz as métricas financeiras essenciais da empresa **XP-Bucks**, com foco na **Demonstração de Resultado de Exercício (DRE)**. O dashboard deve fornecer insights claros e acionáveis para auxiliar na tomada de decisões estratégicas.

## Requisitos do Dashboard

### 1. **Métricas Financeiras Essenciais**
O dashboard deve incluir as seguintes métricas:
- **Receita Bruta**: Total de vendas realizadas.
- **Receita Líquida**: Receita bruta menos descontos e devoluções.
- **Custo dos Produtos Vendidos (CPV)**: Custos diretos associados à produção.
- **Lucro Bruto**: Receita líquida menos CPV.
- **Despesas Operacionais**: Custos indiretos (administrativos, comerciais, etc.).
- **Lucro Operacional**: Lucro bruto menos despesas operacionais.
- **Lucro Líquido**: Lucro operacional menos impostos e outras despesas não operacionais.
- **Margem Bruta**: (Lucro Bruto / Receita Líquida) * 100.
- **Margem Líquida**: (Lucro Líquido / Receita Líquida) * 100.

### 2. **Funcionalidades do Dashboard**
- **Visualização Interativa**: Gráficos e tabelas que permitam filtrar dados por período (mensal, trimestral, anual).
- **Comparativo Temporal**: Possibilidade de comparar métricas entre diferentes períodos.
- **Alertas e Indicadores**: Destaque de métricas que estejam fora do esperado (ex.: margens abaixo do objetivo).

### 3. **Tecnologias Aplicadas**
- **Ferramentas de BI**: Power BI.
- **Linguagens de Programação**: DAX - Data Analysis Expressions.
- **Banco de Dados**: Excel contendo a base de dados da controladoria financeira da XP-Bucks.

### 4. **Design e Usabilidade**
- **Layout Limpo e Intuitivo**: Organização clara das informações, com foco na usabilidade.
- **Interatividade**: Power BI Desktop e Power BI Serviços.
- **Personalização**: Possibilidade de adicionar ou remover métricas conforme a necessidade do usuário.

## Entregáveis
1. **Código Fonte**: Repositório no GitHub com o código utilizado para criar o dashboard.
2. **Dashboard Funcional**: publicado ou arquivo do dashboard pronto para uso.
3. **Documentação**: Arquivo `README.md` explicando o projeto, tecnologias utilizadas e instruções para execução.
4. **Relatório de Análise**: O desempenho financeiro da XP-Bucks para o período analisado mostra sinais positivos, com crescimento na receita líquida e estabilidade no lucro operacional. No entanto, é necessário atenção aos custos e despesas para garantir a sustentabilidade da margem líquida. O dashboard desenvolvido permitiu um acompanhamento contínuo dessas métricas, facilitando decisões estratégicas ágeis e embasadas.
